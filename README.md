# IvanovService — Telegram Mini App

Мини-приложение внутри Telegram для бота **@IvanovServiceBot**: клиент смотрит услуги и цены, работы и контакты, оформляет заявку, а заявка приходит вам в Telegram.

---

## 1. Как это устроено (простыми словами)

```
Клиент в Telegram
   │  открывает приложение кнопкой в боте
   ▼
public/  (страница: index.html + styles.css + app.js + config.json)
   │  заявка + «подпись» Telegram (initData)
   ▼
server/server.js  (ваш сервер в интернете)
   │  1. проверяет подпись — что заявку правда прислал этот человек из Telegram
   │  2. проверяет поля, ограничивает спам (лимиты)
   │  3. отправляет заявку вам через Bot API (токен хранится только тут)
   ▼
Вам в Telegram приходит сообщение «Новая заявка №…»
```

- **Токен бота есть только на сервере**, в переменной окружения `BOT_TOKEN`. В браузер он не попадает (проверено автотестом).
- **«Заявка отправлена» показывается только после того, как сервер подтвердил**, что Telegram принял сообщение. Если что-то не так — клиент видит понятную ошибку.
- Сервер на чистом Node.js, **без сторонних библиотек** — нечего обновлять и меньше уязвимостей.

### Файлы

| Файл | Что внутри |
|---|---|
| `public/config.json` | **Всё, что вы будете менять:** цены, услуги, доп. услуги, сроки, портфолио, контакты |
| `public/index.html` | Разметка экранов |
| `public/styles.css` | Дизайн (Liquid Glass, тёмно-синий) |
| `public/app.js` | Логика: навигация, форма, Telegram API |
| `public/assets/` | Иконка и обложки для портфолио |
| `server/server.js` | Сервер: раздаёт страницу и принимает заявки |
| `.env.example` | Список настроек сервера с объяснениями |
| `tests/api.test.js` | Автотест сервера (`npm test`) |
| `tests/ui.test.js` | Автотест интерфейса в браузере (нужен Playwright) |

### Как менять цены и работы

Откройте `public/config.json`:
- цена: поле `price` (число). `null` — «Индивидуально». `"from": true` — добавится «от».
- доп. услуги: `price: null` показывается как «По договорённости». Если впишете число — появится цена.
- новая работа в портфолио: скопируйте блок в `portfolio`, укажите `title`, `description`, `url` (ссылка на ролик) и `cover` (например `assets/work1.jpg` — файл положите в `public/assets/`).

После изменения файла на хостинге сервер нужно перезапустить (на Render это происходит само после загрузки изменений в GitHub).

## 2. Запуск на своём компьютере

Нужен Node.js 18 или новее (https://nodejs.org → LTS).

```bash
cd ivanov-miniapp
cp .env.example .env      # на Windows: copy .env.example .env
npm start
```

Откройте http://localhost:3000 — интерфейс работает в обычном браузере.

- Без `BOT_TOKEN` и `OWNER_CHAT_ID` в `.env` заявки не принимаются (сервер честно отвечает «приём не настроен»).
- Из обычного браузера заявки по умолчанию тоже не принимаются — только из Telegram, где есть подпись. Для проверки можно временно поставить `ALLOW_BROWSER_ORDERS=true`.
- Автотест сервера: `npm test` (настоящий токен не нужен — используется поддельный Telegram).

## 3. Публикация в интернете (бесплатно, Render)

Telegram открывает Mini App только по **HTTPS**. Render даёт HTTPS автоматически.

1. Зарегистрируйтесь на https://github.com и создайте **приватный** репозиторий, например `ivanov-miniapp`.
2. Загрузите туда всё содержимое папки (кнопка *Add file → Upload files*). Файл `.env` **не загружайте** — его там и не должно быть.
3. Зарегистрируйтесь на https://render.com (можно войти через GitHub).
4. *New → Web Service* → выберите репозиторий.
   - Runtime: **Node**
   - Build Command: оставьте пустым (или `npm install`)
   - Start Command: `npm start`
   - Instance type: **Free**
5. В разделе **Environment** добавьте переменные (значения вписываете только туда):
   - `BOT_TOKEN` — токен бота (см. ниже)
   - `OWNER_CHAT_ID` — ваш числовой ID (см. ниже)
6. Нажмите *Create Web Service*. Через пару минут появится адрес вида `https://ivanov-miniapp.onrender.com`.
7. Проверка: откройте `https://ВАШ-АДРЕС/api/health` — должно быть `{"ok":true,"configured":true}`.

Важно про бесплатный тариф (условия на момент написания, проверьте на сайте Render): сервер «засыпает» без посетителей, и первое открытие после паузы может занять до минуты. Для старта это нормально; если мешает — платный тариф или другой хостинг (Railway, Fly.io, свой VPS) — код тот же.

### Где взять значения

- **BOT_TOKEN**: в Telegram откройте @BotFather → `/mybots` → IvanovServiceBot → *API Token*. Вставляйте его **только** в настройки Render или в локальный `.env`. Не отправляйте в чаты, не публикуйте, не загружайте в GitHub. Если токен засветился — там же *Revoke current token* и обновите его в Render.
- **OWNER_CHAT_ID**: напишите боту @userinfobot — он пришлёт ваш `Id` (число). Затем откройте **своего** бота @IvanovServiceBot и нажмите «Старт» — иначе бот не сможет вам написать.

Если ваш бот уже работает на другом сервисе (конструктор или свой код) — это не мешает: Mini App только **отправляет** сообщения от имени бота и не принимает его обновления.

## 4. Подключение к боту в Telegram

### Кнопка меню (слева от поля ввода в чате с ботом)
1. @BotFather → `/mybots` → **IvanovServiceBot** → **Bot Settings** → **Menu Button** → **Configure menu button**.
2. Отправьте адрес приложения: `https://ВАШ-АДРЕС.onrender.com`
3. Отправьте название кнопки, например `Заказать монтаж`.

Теперь в чате с ботом появится кнопка, открывающая приложение.

### Ссылка на приложение (по желанию — для шапки Instagram, сторис)
1. @BotFather → `/newapp` → выберите IvanovServiceBot.
2. Название, описание, картинка 640×360 (можно пропустить, если BotFather разрешает), URL — тот же адрес.
3. Короткое имя, например `app`. Получится ссылка `https://t.me/IvanovServiceBot/app`.

Меню BotFather время от времени меняется: если пункт называется иначе, ищите *Mini App*, *Menu Button* или *Configure Mini App* в Bot Settings.

> Если ваш бот работает на конструкторе, который сам управляет кнопкой меню, он может перезаписать эту настройку. Тогда используйте ссылку из `/newapp` или добавьте кнопку «Открыть приложение» в сценарий конструктора.

### Проверка
Откройте бота с телефона → кнопка меню → оформите тестовую заявку. Вам должно прийти сообщение «🎬 Новая заявка №…», а клиенту (вам же) — «✅ Заявка получена».

## 5. Безопасность — что уже сделано

- Подпись Telegram (`initData`) проверяется на сервере по официальному алгоритму HMAC-SHA256, со сроком действия (сутки).
- Данные из `initDataUnsafe` в браузере используются только чтобы подставить ваш @username в поле — сервер им не доверяет.
- Лимиты: не больше 5 заявок за 10 минут от одного пользователя и 20 запросов с одного IP.
- Повторное нажатие или повторная отправка после обрыва связи не создают дубль заявки.
- Максимальный размер запроса — 10 КБ; все поля проверяются на сервере; текст экранируется перед отправкой в Telegram.
- Защита от выхода за пределы папки `public/`, заголовки безопасности (CSP, nosniff).

Ограничение: лимиты и защита от дублей хранятся в памяти сервера и сбрасываются при перезапуске. Для небольшого потока заявок этого достаточно.

- Цены, услуги и работы по-прежнему меняются только в public/config.json.

## Версия 2.2 (22.10.2026): подписки и план клиента

**Что добавлено**
- На экране «Цены» есть переключатель **«Разовый монтаж / Подписки»**. Разовый монтаж работает как раньше.
- **6 тарифов** (BASIC, GO, PRO, PRO PLUS, MAX, ULTRA), и в каждом два уровня: **Standard Motion** (2D) и **Advanced 3D**. В карточке тарифа видно, сколько роликов и какой они длины, что входит, цену выбранного уровня и итоговые условия. Внизу кнопка «Оформить заказ».
- В форме заказа вверху показана выбранная подписка, а ссылка на материалы для подписки не обязательна.
- Заявка на подписку приходит вам в Telegram с тарифом, уровнем и ценой. «Заявка отправлена» клиент видит только после того, как Telegram принял сообщение (как и раньше).
- **План клиента.** Под заявкой на подписку есть кнопка **«💳 Оплачено — включить план»**. Нажимаете её, когда получили оплату. После этого у клиента:
  - на главной рядом с именем появляется бейдж тарифа (PRO, MAX…);
  - в профиле — карточка «Подписка активна до …»;
  - от бота приходит сообщение.

  План действует 30 дней. Повторное нажатие после новой оплаты продлевает его ещё на 30 дней. Кнопка **«⏹ Отключить план»** выключает план.

**Где менять цены и объёмы:** только в `public/config.json` → `subscriptions` (`plans`: роликов в месяц, максимальная длина, цены по уровням; `levels`: названия уровней и что в них входит). Сервер берёт данные оттуда же, поэтому подменить цену из браузера нельзя.

**Важно**
- Оплата в приложении **не принимается**. План включаете вы вручную, когда деньги действительно пришли. Онлайн-оплату можно подключить позже через платёжный сервис, но для этого нужен оформленный продавец (например, самозанятость), и решать это лучше вместе с родителями.
- На бесплатном Render файл `data/orders.json` может пропасть после перезапуска. Тогда пропадут и активные планы. Чтобы этого не было, подключите Persistent Disk и укажите путь в `ORDERS_FILE`.
